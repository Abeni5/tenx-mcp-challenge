# Insights Gained

## What I Learned About AI Control
- AI agents are highly sensitive to rules and instructions.
- Clear rules reduce hallucination and improve accuracy.
- The agent behaves more reliably when expectations are explicit.

## How Rules Affect Thinking and Output
- Rules guide how the AI reasons before answering.
- Small wording changes can significantly alter behavior.
- Defining roles makes the AI think like a teammate, not a chatbot.
- Structured rules improve both code quality and communication.
