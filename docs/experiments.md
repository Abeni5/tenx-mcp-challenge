# AI Agent Experiments

## Prompt Before Rules
"Create a FastAPI endpoint for user registration."

### Behavior Observed
- The AI immediately generated code.
- Made assumptions about database and validation.
- Minimal explanation.

## Prompt After Rules
"Create a FastAPI endpoint for user registration."

### Behavior Observed
- The AI asked clarifying questions (database, auth, validation).
- Code was more structured and readable.
- Included explanations and best practices.

## What Changed in AI Behavior
- Reduced assumptions.
- More professional tone.
- Better code organization.
- Improved reasoning and explanation.
