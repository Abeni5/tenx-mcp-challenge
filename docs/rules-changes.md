# Rules File Changes

## What I Changed in the Rules
- Defined the AI agent’s role as a senior software engineer.
- Added instructions to ask clarifying questions before coding.
- Enforced clean, readable, and production-quality code.
- Added structured debugging behavior.
- Set collaboration and communication expectations.

## Why I Added Each Rule
- Role definition helps align the AI’s mindset with real-world engineering.
- Clarifying questions reduce wrong assumptions and hallucinations.
- Clean code rules improve readability and maintainability.
- Debugging rules encourage root-cause analysis instead of random fixes.
- Collaboration rules make the AI behave more like a human teammate.
